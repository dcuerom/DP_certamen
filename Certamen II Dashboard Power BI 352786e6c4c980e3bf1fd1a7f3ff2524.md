# Certamen II | Dashboard Power BI

Tipo de evaluación: Certamen
Áreas: Universidad (https://www.notion.so/Universidad-2233a9cfe9cd437495a369062010a736?pvs=21)

El objetivo de esta evaluación es desarrollar un dashboard en Power BI a partir de una base de
datos de RRHH con 10.000 registros. Los estudiantes deberán limpiar, estructurar y analizar la
información para generar indicadores clave que apoyen la toma de decisiones.

1. Objetivos del Proyecto
    - Limpiar y preparar datos con errores intencionales.
    - Construir indicadores clave de RRHH.
    - Desarrollar un dashboard interactivo en Power BI.
    - Generar insights y recomendaciones.
2. Procesos de RRHH a Analizar
    - Dotación
    - Rotación
    - Equidad Salarial
    - Capacitación
    - Desempeño
    - Diversidad e Inclusión
3. Requerimientos del Dashboard
    - Visualizaciones claras y ejecutivas
    - Segmentación por área, género, antigüedad, etc.
    - KPIs relevantes
    - Uso de filtros dinámicos
    - Coherencia en datos
    1. Formato de Entrega
    La entrega se realizará mediante una presentación en Power BI.
    Cada grupo deberá exponer su dashboard en un máximo de 10 minutos.
    Fecha de presentación: viernes 7 de mayo.
    Horario: durante la hora de clases.
